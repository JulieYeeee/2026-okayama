# 2026 Okayama Trip

旅伴討論用的岡山周邊旅行候選頁面。

## 頁面內容

- 旅行偏好整理
- 宮島、直島、倉敷、廣島、尾道、高松比較
- 倉敷 vs 尾道的選擇方式
- 目前推薦的優先候選

網站本體是純 `index.html`，不需要 build。

## 用 GitHub Pages 發布

> 目前這個 repository 是 private。若希望任何拿到網址的人都能直接看到，最簡單的方式是先將 repository 改成 public。

1. 到 GitHub repository 的 **Settings**
2. 進入 **Pages**
3. `Build and deployment` 的 Source 選 **Deploy from a branch**
4. Branch 選 `main`
5. Folder 選 `/ (root)`
6. 儲存後，GitHub 會提供公開網址

一般網址會是：

`https://julieyeeee.github.io/2026-okayama/`
